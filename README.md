# Bellarix - Premium Digital Experiences

Welcome to the official frontend repository for **Bellarix**, a premium IT solutions agency specializing in AI Automation, Web Development, and App Development based in Nagpur, India.

![Bellarix Theme](https://bellarix.in/Logo1-removebg-preview.png)

## Overview

Bellarix is an ultra-modern, fully responsive Single Page Application (SPA) built with Angular 19 and Bootstrap 5. It features cutting-edge design trends such as:
- **Glassmorphism** interfaces with frosted-glass effects.
- **Dynamic CSS Animations** including floating cards, sweeping shines, and typing effects.
- **Dark-mode aesthetic elements** beautifully integrated into a bright, silver, and black theme.
- **Comprehensive SEO Integration** utilizing JSON-LD structured data and Open Graph tags.

## Tech Stack

- **Framework:** Angular 19
- **Styling:** Bootstrap 5.3 & Vanilla CSS
- **Animations:** AOS (Animate On Scroll) & Custom CSS Keyframes
- **Icons:** Bootstrap Icons & Lucide Icons (via SVG)
- **Routing:** Angular Router (Configured for anchor scrolling)

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) and the [Angular CLI](https://angular.io/cli) installed globally on your machine.

```bash
npm install -g @angular/cli
```

### Installation

1. **Clone the repository** (if applicable) or navigate into the project directory:
   ```bash
   cd Bellarix_v1
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Development Server

Run `ng serve` or `npm start` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

```bash
npm run start
```

### Build for Production

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory.

```bash
npm run build
```

## Project Structure

- `src/index.html`: The root HTML file, fully optimized with SEO tags and structured data.
- `src/styles.css`: Global styling, defining the Bellarix color tokens (`--bx-black`, `--bx-silver`) and overarching typography rules.
- `src/app/components/`: Contains all the modular sections of the application (Navbar, Hero, Services, Projects, Testimonials, Footer, Contact).
- `src/app/pages/`: Contains the main layout views (e.g., `home.html` which stacks the components).
- `public/`: Static assets including images, logos, `robots.txt`, and `sitemap.xml`.
